# DivyaDrishti AI — Reports & Evaluation Artifacts

This directory stores evaluation, cross-dataset testing, and training outputs generated by the DivyaDrishti (दिव्यदृष्टि) AI deepfake detection pipeline:

- `training_curves.png`: Training & validation loss and accuracy curves per epoch.
- `training_history.json`: Epoch-by-epoch loss, accuracy, and learning rate values.
- `training.log`: Detailed logger output from the training loop.
- `confusion_matrix.png`: Heatmap visual of true vs predicted real/fake labels.
- `roc_curve.png`: Receiver Operating Characteristic curve with AUC score.
- `evaluation_summary.json`: JSON output of test accuracy, precision, recall, F1, and AUC.
- `evaluation_report.md`: Markdown summary table formatted for documentation and presentations.
- `evaluation.log`: Detailed log from model evaluation runs.
